# Guide: Redesign / Mockup

## Use when
Visual overhaul, rebrand, or uploaded mockup/reference image.

## Usually owe (if unpaid)
1. **snapshot** (bind) — mockup path; **not** gallery inspiration first
2. **observe** — correct port/app
3. **verify** — hard criteria; sections → ship if gated

Inspiration only if direction still open and snapshot is not the path.

## Skip
Re-inspiration after Spec/mockup bound; soft text-only “mockup match.”

## Ship note
Dashboard may challenge equal-weight KPIs; settings/auth use form/footer — don’t force KPI fixes on settings.

## Done condition
Snapshot/Spec honored; data.verified=true; checklist/ship clear when required.
