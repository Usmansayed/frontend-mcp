# Guide: Hotfix / Polish

## Use when
Bug, surgical CSS, blur/opacity nudge (hotfix/surgical/debug).

## Usually owe
1. **observe** correct port (blocking first)
2. Smallest fix
3. **verify** with hard criteria (computed style / JS)

Opacity/blur “looks the same” → measure competing overlays/washes.

## Skip
Inspiration, foundation, ship — **unless** sticky design_driven/redesign draft this episode → finish checklist + Ship Council.

## Done condition
data.verified=true for the symptom; ladder only when sticky design requires it.
