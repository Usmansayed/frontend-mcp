# Guide: Greenfield

## Use when
New product UI / landing / no mockup (design_driven).

## Usually owe (if unpaid)
1. **inspiration OR snapshot/figma** — one progressive collect 3–5 refs; stop when usable
2. **component** — if foundation unpaid
3. **observe** then **verify** — (+ sections/ship if gated)

## Skip
SEO, ritual 2–3 inspiration loops, ship before reference+foundation paid/skipped.

## Implementation boundary
Do not jump to Design Review / soft verify first.

## Done condition
Reference + foundation settled (or valid skip); Done ladder clear when gated.
